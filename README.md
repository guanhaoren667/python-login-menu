# Python 登入驗證與多功能選單練習程式

## 專案說明

使用者輸入展示用帳號與密碼並通過驗證後，
可以透過數字選單選擇並執行不同功能。

## 展示用帳號

- 帳號：`123`
- 密碼：`456`

上述帳號與密碼僅供專案操作展示使用，不涉及真實帳號資訊。

## 功能概述

整合展示帳號與密碼驗證，以及 8 項 Python 基礎練習功能：

1. BMI 計算
2. 攝氏與華氏溫度換算
3. 九九乘法表
4. 簡易收銀計算
5. 撲克牌點數加總
6. 數字位數加總
7. 階乘計算
8. 基礎四則與取餘數運算

## 使用技術

- Python
- `if / elif / else` 條件判斷
- `for` 迴圈與巢狀迴圈
- `list`
- `input()` 使用者輸入
- `int`、`float`、`str` 型態轉換

## 執行方式

1. 下載 `main.py`。
2. 確認電腦已安裝 Python。
3. 在 `main.py` 所在資料夾執行：

```bash
python main.py
```

4. 輸入展示用帳號與密碼。
5. 輸入功能編號，並依照畫面指示操作。

## 個人完成內容

自行完成展示帳密驗證、數字功能選單及 8 項 Python 基礎練習功能的整合，並依照使用者輸入執行對應功能。

核心功能已完成，作為 Python 條件判斷、迴圈、資料型態轉換及文字選單整合的基礎練習作品。
