# Python 登入驗證與多功能選單練習程式
 
## 專案說明
 
這是使用 Python 製作的文字介面練習程式。
 
使用者輸入展示用帳號及密碼並通過驗證後，可以透過數字選單選擇不同功能。
 
## 展示用帳號
 
- 帳號：123
- 密碼：456
 
上述帳號與密碼僅供專案操作展示使用，不涉及真實帳號資訊。
 
## 主要功能
 
1. 登入帳號與密碼驗證
2. BMI 計算
3. 攝氏與華氏溫度換算
4. 九九乘法表
5. 簡易收銀計算
6. 撲克牌點數加總
7. 數字位數加總
8. 階乘計算
9. 簡易算術與取餘數運算
 
## 使用技術
 
- Python
- if / elif / else 條件判斷
- for 迴圈與巢狀迴圈
- list
- input 使用者輸入
- int、float、str 型態轉換
 
## 執行方式
 
1. 下載 `main.py`
2. 使用 Python 執行程式
3. 輸入展示用帳號及密碼
4. 輸入功能編號並依照畫面操作
 
## 專案成果
 
將帳密驗證、數字功能選單，以及八項 Python 練習功能整合在同一支程式中。
